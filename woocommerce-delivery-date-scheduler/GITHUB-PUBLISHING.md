# GitHub publishing notes

## Suggested repository name

`woocommerce-delivery-date-scheduler`

## Suggested GitHub description

Lightweight WooCommerce delivery-date scheduler with checkout date tiles, Arabic/RTL support, HPOS, admin/email display, and automatic Scheduled Delivery to Packing status automation.

## Author and website

**Mazen Bassiso**  
https://fa7ma.com

When creating the repository, add `https://fa7ma.com` to the GitHub **Website** field in the repository About section.

## Suggested GitHub topics

Add these in the repository **About → Topics** section:

`woocommerce`, `wordpress`, `wordpress-plugin`, `delivery-date`, `delivery-scheduler`, `checkout`, `order-status`, `scheduled-delivery`, `arabic`, `rtl`, `hpos`, `ecommerce`

## Suggested release title

`WooCommerce Delivery Date Scheduler v1.5.0`

## Suggested release notes

Public-ready release with English/Arabic documentation and localization, WooCommerce HPOS support, delivery-date checkout tiles, admin/email display, Scheduled Delivery/Packing workflow, and a bounded daily cron for due orders.

## Important compatibility note

Do not advertise WooCommerce Checkout Block support yet. The current UI uses classic checkout hooks.
